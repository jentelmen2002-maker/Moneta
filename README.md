# Moneta для Android (APK)

Готовый Android-проект: приложение «Moneta» упаковано в WebView, все файлы (React, шрифты, иконки) лежат внутри APK.
Интернет не нужен. Цели хранятся на телефоне в `localStorage` и дублируются в IndexedDB.

## Способ 1. Собрать APK на GitHub (ничего ставить не нужно)
1. Создайте на github.com новый репозиторий (можно приватный).
2. Загрузите в него **содержимое** этой папки (кнопка «Add file → Upload files»; папка `.github` должна попасть внутрь).
   Если интерфейс не даёт загрузить скрытую папку `.github`, создайте файл `.github/workflows/build-apk.yml` вручную и вставьте в него текст из архива.
3. Откройте вкладку **Actions** → **Build APK**. Сборка стартует сама после загрузки; если нет — нажмите **Run workflow**.
4. Через 3–6 минут откройте завершённый запуск и скачайте артефакт **Moneta-apk** (zip с `app-debug.apk`).
5. Скопируйте `app-debug.apk` на телефон и откройте. Android попросит разрешить установку из этого источника.

## Способ 2. Собрать в Android Studio
1. Установите Android Studio, откройте эту папку как проект и дождитесь синхронизации Gradle.
2. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Замечания
- APK подписан отладочным ключом: для личной установки этого достаточно. Для Google Play нужен релизный ключ и сборка AAB.
- Чтобы обновить приложение, замените файлы в `app/src/main/assets/` и увеличьте `versionCode` в `app/build.gradle`.
  Новый APK ставится поверх старого, цели при этом сохраняются (при условии, что подпись та же, то есть сборка идёт из того же репозитория).
- Системная кнопка «Назад» сначала закрывает окно или экран внутри приложения, на главном экране приложение сворачивается.
- Выбор картинки для цели (аватар) открывает системную галерею.
